Customer Orders Tracker

This was a paired project assigned in my Software Engineering class. We were given the freedom to choose the type of software we wanted to build.

My Role: Focused on developing the website, ensuring a seamless UI/UX experience, Firebase authentication, and software download functionality.

The Customer Orders Tracker is a web-based platform designed to streamline order management for General Motors' (GM) parts distribution. This system allows users to sign up, securely log in, track orders, manage feedback, and download order tracking software.

Key Features:

  • User Authentication: Secure login with Firebase Authentication (2FA using email & phone).
  • Order Tracking: Manage and track customer orders in real-time.
  • Downloadable Software: Users can log in to download the order tracking software.
  • Feedback System: Users submit feedback stored in Firebase for future improvements.
  • Firebase Integration: Authentication, database, and hosting for seamless cloud-based functionality.
  • Modern UI/UX: Intuitive and user-friendly web interface.

Modern Business Solutions (MBS) Application

This project was assigned to my group by a client for our Senior Capstone class.

The Modern Business Solutions (MBS) application is a mobile platform for business planning and management, built using Flutter. It enables users to create structured business templates, track deadlines with reminders, visualize data through charts, and collaborate via built-in video conferencing.

Key Features: Secure authentication, business template creation, data visualization, reminders, cloud storage, and integrated video conferencing.

MBS enhances business productivity by providing a centralized platform for organization, planning, and communication.
